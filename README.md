# Portfolio — Pol Serrano Aromí

Portfolio estático hecho desde cero con HTML, CSS y JavaScript. No necesita Node, npm ni frameworks.

## Estructura

- `index.html` — contenido y estructura.
- `style.css` — diseño, responsive y animaciones.
- `script.js` — menú móvil, reveal al hacer scroll, año automático y copiar email.
- `assets/profile.jpg` — tu foto de perfil.
- `assets/projects/web-corporativa.png` — captura del proyecto 1.
- `assets/projects/oculus.png` — captura del proyecto 2.
- `assets/projects/agutin-service-system.png` — captura del proyecto 3.

## Para ponerlo en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube todos los archivos manteniendo las carpetas.
3. En GitHub ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige `main` y `/root`.
6. Guarda y espera a que GitHub Pages publique la web.

Al ser HTML/CSS/JS puro, no hace falta ningún build ni comando de npm.
